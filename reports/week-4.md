# 4주차 — 다국어 기준선과 로컬 평가기 점검

## 목표

영어·중국어·프랑스어·일본어 기준선을 같은 모델·프롬프트·생성 설정으로 수집하고, 코드 지표와 로컬 LLM 평가 점수를 분리한다. 원어민 검수가 불가능하므로 로컬 평가기 점수는 대리 신호로만 취급한다.

## 고정 조건

- 데이터셋: [`evaluation-set-v2.json`](../data/evaluation-set-v2.json), 총 40건(언어별 10건). v1 20건은 보존했다.
- 데이터셋 권리/분리: 사례와 라벨은 평가용으로 직접 작성했으며, 학습·프롬프트 예시·검색 인덱스에 넣지 않는다. 원어민의 독립 검수는 받지 않았다.
- 생성 모델: `qwen3.5:9b`, Ollama digest `d63f830f28d515fefea546f213fca7a75e9dd5176ef51a6deabc952d1c99a911` (7,639,229,431 bytes), Ollama `0.40.13`.
- 장비: Apple M4, arm64, 메모리 16 GiB.
- 생성 설정: temperature `0.1`, max tokens `500`, seed `42`, stream `false`.
- 프롬프트 revision SHA-256: 언어별로 실행 JSON의 `prompt_sha256_by_language`에 기록했다.
- 결과 파일: `results/model-evaluation-2026-11-02T13-08-45.871Z.json` (로컬 결과물, Git 제외).
- 로컬 평가: 같은 `qwen3.5:9b`, 고정 루브릭·temperature `0`·seed `42`; 40건 판정 결과는 `results/local-judge-evaluation-latest.json`에 저장했다 (로컬 결과물, Git 제외).

이 기준선은 `extractPhrases`의 모델 출력 결과를 평가하며, API의 후속 `validatePhrases` 필터링을 거친 사용자 노출 결과와는 구분한다.

“정답 표현 문자열 일치”는 각 사례에 적어둔 단일 참고 표현과의 일치율이다. 허용 가능한 다른 표현까지 포괄하는 정답률은 아니며, 원어민이 검수한 gold label도 아니다. 특히 낮은 일치율만으로 표현의 자연스러움을 단정하지 않는다.

### 로컬 평가기 대리 점수 (1~3)

| 언어 | 자연스러움 | 문맥 적합성 | 초급 유용성 | 언어 품질 | 필드 품질 |
|---|---:|---:|---:|---:|---:|
| 중국어 | 3.00 | 2.90 | 2.90 | 3.00 | 3.00 |
| 영어 | 2.90 | 3.00 | 2.90 | 3.00 | 2.90 |
| 프랑스어 | 2.90 | 3.00 | 2.90 | 3.00 | 2.70 |
| 일본어 | 3.00 | 2.60 | 2.60 | 3.00 | 1.70 |

이 점수는 원어민 판정이나 실제 사용 빈도의 근거가 아니다. 같은 Qwen 계열을 생성기와 평가기로 사용해 자기 편향 가능성도 있다. 실제 오류와 맞지 않는 평가가 확인됐다. 예를 들어 원문에 없는 `离...很近` 출력(`zh-04`)에도 평가기는 모든 항목에 3점을 줬다. 일본어 읽기 필드가 가나인 정상 형식도 일부 평가 근거에서 오류로 지목했다. 따라서 원문 일치·언어·발음 스크립트 같은 판정 가능한 항목은 평가기 점수보다 코드 검사로 확인해야 한다.

## 오류 선택 및 다음 단계

다음 개선 대상으로 **일본어 읽기 필드의 로마자·오독 출력**을 선택한다. 기준선 원시 출력에서 `shigoto ni iku mae ni`, `wakaranai koto ga` 같은 로마자 읽기가 나왔고, 다른 사례에서도 한자 표현과 읽기가 맞지 않는 정황이 확인됐다. 다음 주 보상 하네스에 가나 전용 형식 검사를 추가하고, 형식 실패를 별도 보상 항목으로 기록한다. 같은 40건에서 언어별 회귀를 확인한다. 읽기 필드는 단순히 값이 있는지만 보지 말고 가나 스크립트 형식과 원문 표현과의 대응 오류를 따로 기록한다.

## 미완료·해석 한계

- 원어민 검수는 받지 못했다. 자연스러움과 사용 빈도는 검증되지 않았다.
- 평가기 오류 주입과 동일 출력 반복 실행에 따른 점수 안정성 점검은 아직 수행하지 않았다. 현재 대리 점수는 탐색 기록이며 개선 판정에 쓰지 않는다.
- 데이터셋 정답은 각 사례당 참고 표현 하나뿐이다. 전문가 검수 전까지 모델 비교의 완전한 정답으로 해석하지 않는다.
- 원문 포함 검사에서 프랑스어 아포스트로피 정규화 오탐이 발견됐다. 다음 실행부터 곡선/직선 아포스트로피를 정규화해 판정하고, 변경 사실을 결과에 남긴다.
