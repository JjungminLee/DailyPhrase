# 미결정 사항: 피드 관리자와 수집 배치

현재 기능은 로컬 학습용입니다. 아래 항목은 제품 운영 방식을 정하기 전까지 미결정으로 남깁니다.

1. **중국어 기본 피드의 문자 체계**: 현재 중국어(`zh`) 기본 피드는 대만 중앙통신사 CNA의 번체 중국어 문화 피드입니다. 간체 중국어 자료도 기본으로 포함해야 하나요?
2. **기본 매체 선정 기준**: 현재 언어별로 VOA Learning English, CNA, Le Monde, nippon.com의 RSS 하나씩을 기본 구독으로 제공합니다. 사용자가 지정한 매체가 있거나, 일반 뉴스 대신 에세이·문화 아티클을 우선해야 하나요?
3. **콘텐츠 이용 범위**: Le Monde와 CNA는 RSS 이용을 개인·비상업 용도로 제한합니다. 이 앱을 공유하거나 공개 배포할 계획이 생기면 해당 매체의 이용 조건과 필요한 허가를 먼저 확인해야 합니다.
4. **운영 환경의 저장소와 관리자 권한**: 구독은 현재 PC의 `data/subscriptions.json`에 저장됩니다. 여러 기기에서 공유하거나 서버에 배포한다면 저장소, 인증 및 관리자 권한을 정해야 합니다.
5. **수집 주기와 실행 위치**: 로컬 크롤러 기본 간격은 15분이며 `CRAWL_INTERVAL_SECONDS`로 바꿀 수 있습니다. 항상 켜진 PC, Windows 작업 스케줄러, 클라우드 배치 중 어느 방식을 사용할지는 정하지 않았습니다.
6. **아티클 보관 및 삭제 정책**: 수집 항목은 로컬 JSON에 최대 5,000건 보관합니다. 보관 기간, 수동 삭제, 재수집 정책은 정하지 않았습니다.
7. **오늘의 표현 생성 실패 처리**: 모델 제공자 설정이 없거나 생성에 실패했을 때 재시도 및 표시 정책은 정하지 않았습니다.
8. **배치 성능 비교 범위**: 현재 스터디는 등록된 피드에 대한 동시성 1·2·4 비교입니다. 운영 규모 추정, 반복 횟수, 네트워크 영향을 포함한 비교 방법은 정하지 않았습니다.
