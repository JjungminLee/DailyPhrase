# 모델 품질 스터디에서 정할 항목

다음 실험을 재현 가능하게 만들기 위해 스터디에서 정하거나 기록할 항목입니다.

1. **기준 모델 식별**: Ollama 태그와 가능한 경우 모델 digest, 양자화 형식, 프롬프트 revision을 결과 파일에 기록합니다.
2. **평가셋**: 영어·중국어·프랑스어·일본어를 균형 있게 포함하고, 학습에 쓰지 않는 검수된 예시를 고정합니다.
3. **평가 기준**: 규칙으로 확인할 원문 근거·언어·형식과 Jev가 보조 판단할 자연스러움·문맥 적합성·학습 가치를 분리합니다. 1~3점 rubric의 사람 검수와 Jev 판정 불일치를 확인하고, 사람 검토를 최종 판단으로 둡니다.
4. **학습 데이터 사용 권한**: 기사 전문을 학습 데이터로 복사하지 않습니다. 사용 권한이 확인된 짧은 예시나 사용자가 제공한 문장을 사용합니다.
5. **튜닝 방식**: 현재 Qwen 모델과 학습 라이브러리의 호환성을 확인하고, 전체 가중치 재학습보다 LoRA 같은 파라미터 효율 튜닝을 우선 검토합니다.
6. **실행 환경**: GPU/메모리, 드라이버, 학습 시간과 저장 공간을 기록합니다. 로컬 장비에서 재현할 수 없으면 환경 제약과 가장 작은 대안을 남깁니다.
7. **품질과 효율의 구분**: 품질 지표와 p50·p95 지연, 메모리 사용량을 따로 비교하고, 개선되지 않은 결과도 기록합니다.
