# 미결정 사항

요구사항에서 사용자가 선택하거나 실제 요청으로 확인해야 한다고 한 항목입니다. 답을 정하기 전까지 기본 설정은 feeds 빈 배열, 외부 AI 호출 없음, AWS 미배포 상태입니다.

1. **모델 공급자와 모델명**: AWS Lambda에서 호출할 실제 모델/서비스는 무엇인가요? 모델 출력 스키마, 리전 가용성, 429 재시도 정책, 인증 정보는 무엇을 사용할까요? 현재 `src/extract/model.mjs`는 선택 전 오류를 반환합니다.
2. **RSS 매체 선택**: 영어·중국어·프랑스어·일본어별 후보 매체 5개를 어떤 기준/출판물 범위로 제안할까요? 피드와 매체 도메인은 실제 HTTP 요청으로 확인해야 하므로 현재 URL을 만들어 넣거나 `verified`로 표시하지 않았습니다. 후보 승인 후 검증 기록을 `docs/feed-check.md`에 추가해야 합니다.
3. **기사 본문 추출**: RSS 요약만 사용할지, 본문 추출에 Readability 계열 라이브러리를 추가할지 결정이 필요합니다. 현재 구현은 RSS 본문/요약 또는 HTML 태그 제거 방식이며, 사이트별 본문 품질을 보장하지 않습니다.
4. **일일 API의 기사 수**: 언어당 최신 기사 1개만 쓸까요, 여러 기사를 합칠까요? 현재 초안은 언어별 피드 한 개와 최신 기사 한 개입니다.
5. **활성 피드 선택**: 후보·검증 결과를 보고 언어별 어떤 피드를 `enabled: true`로 할까요?
6. **배포 방식과 Terraform/provider 버전**: 기존 AWS 과제 템플릿과 사용할 Terraform/AWS provider 버전을 알려주세요. 버전 constraint와 `.terraform.lock.hcl`은 임의로 만들지 않았습니다. `terraform init`도 실행하지 않았습니다.
7. **Terraform state**: 개인 계정에서 로컬 state를 사용할까요, S3 backend를 사용할까요? 현재 backend 설정은 없습니다.
8. **API 접근 제어**: 데모 API를 공개할까요, API key/인증을 추가할까요? 현재 REST API 메서드는 인증 없이 구성됩니다. `api_key_id` output은 생성되지 않아 null입니다.
9. **공유 AWS 계정 설정**: API Gateway CloudWatch 역할은 계정 전역 단일 설정입니다. 기존 설정을 재사용할지 별도 적용할지 확인이 필요합니다. AWS Budgets는 중복/공유 적용 위험 때문에 생성하지 않았습니다.
10. **Owner 태그와 리전**: `owner`, `aws_region`은 실제 값으로 채워야 하므로 tfvars에 넣지 않았습니다.
11. **고정 데이터셋 20건**: 성공/차단 샘플을 구성할 실제 feed ID와 기사 URL 및 차단 사유를 선택해야 합니다. 확인되지 않은 URL이나 예상 결과를 임의로 기록하지 않았습니다. 따라서 `npm run quality`는 현재 의도적으로 입력 케이스가 20건이 아니라고 실패합니다.
12. **`POST /check`**: 문장 평가의 성공 응답 필드와 점수/교정 기준을 확정해야 합니다. 모델 선택 전에는 `model_error`를 반환합니다.
13. **출력 제한**: `MAX_INPUT_CHARS=120000`, 응답 본문 2 MB, fetch timeout 8초, Lambda 25초/512 MB, 예약 동시성 5, API rate/burst 5/10, 로그 보존 14일은 절감 우선 초안입니다. 과제 템플릿 및 사용량 계획과 비교해 승인해야 합니다.
14. **프로비저닝/추가 리소스**: provisioned concurrency는 off(미생성), SQS/DLQ는 미생성, Budgets는 미생성 상태입니다. 4주차 실험 전 baseline과 변경 tfvars를 확정해야 합니다.
15. **성과 공유 일정**: 요구사항에는 11/30 이후 결과 공유/재실행 여부가 불명확합니다. Terraform 기반 재생성이 가능하다는 제안이 있지만 최종 일정을 정해야 합니다.
